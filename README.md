TurfZone ⚽🏏

TurfZone is a web-based sports turf booking platform developed using PHP, MySQL, HTML, CSS, and JavaScript. The system allows users to register, log in, browse available turfs, select time slots, make bookings, and manage their profiles. Administrators can view and manage bookings through an admin dashboard.

Browse Available Turfs
